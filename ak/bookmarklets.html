Bookmarklets for SEO, writing & digital marketing

A bit fewer clicks. Another use for that crowded bookmarks bar.

Useful little shortcuts, one bookmark away.

A bookmarklet is a small piece of JavaScript saved as a browser bookmark. Click it to work with the page you're viewing, or send that page's URL to another service.

Quirky little time-savers, in much the same spirit as searching selected text from your browser's right-click menu. A few saved clicks add up. For an occasional task, I often prefer a bookmarklet to another extension or a tab kept open just in case. Save the ones you use and leave the rest here.

How to use a bookmarklet
  1. Show your browser's bookmarks bar. On most desktop browsers: Ctrl/Cmd+Shift+B.
  2. Adjust the tool's settings, if needed.
  3. Drag its bookmark button into the bar.
  4. Open the page you want to work on and click the saved bookmark.

For manual installation copy the code, create a bookmark, and paste it into the bookmark's URL field. Keep the javascript: prefix. Settings update the code and draggable bookmark immediately. If you change them later, save the bookmarklet again; previously saved bookmarks don't update automatically.

If a service accepts a page URL as part of its own address, the Bookmarklet builder can often turn it into a simple shortcut. You'll need the URL format the service expects. For something more specific, you can always ask a chatbot to make a bookmarklet for you.

Too many bookmarks is a familiar problem. Folders and shorter names help. Ordinary website bookmarks can often be recognisable by their icon alone; for these tools, keeping just the emoji in the bookmark's name is another option.

For notes saved as Markdown, use whichever online or local viewer or editor suits you. MarkText is a handy open-source option for working with them locally. Quick notes don't save automatically, so download anything you want to keep.

Two ways to copy the code. The main copy icon copies an encoded bookmarklet URL for installation, preserving spaces and special characters. Expand a code block to find the readable-source copy icon at its bottom right. Both versions run the same JavaScript. Previously saved bookmarklets don't update automatically, so save them again after changing their settings or applying an updated version.

A few practical limits. Page inspection covers the loaded document, rather than an entire website. Browser pages, PDF viewers, content inside frames, site policies and permissions can limit what runs or appears in a report. Mobile installation and feature support vary; use your browser's bookmark editor where available.

Processing and privacy. Most tools work in your browser. External shortcuts share the current URL, link checks request their destinations, and citation export uses your existing session. Page capture loads an external renderer after confirmation. Keyword repetition review counts and highlights text locally; its flags are suggestions to review the copy, not proof of keyword stuffing.

Greek orthography sends your reviewed text to the displayed service after you approve and click Send text & check Greek. By default, it uses LanguageTool. Opening the panel sends nothing. Downloaded results include the checked text and source-page URL.

Page SEO snapshot checks the loaded page in your browser. The optional header check sends a fresh HEAD request using your current session. The preview loads the site's favicon; product thumbnails load only when requested. Opening an external validator shares the page URL. The preview is an approximation, and the checks don't confirm indexing or rich-result eligibility.
