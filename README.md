# alexanderkyriakou.eu

**A personal corner of the web. Part notebook, part playground, part collection of things that caught my attention.**

This is where I write about things, experiment with ideas, build small tools, and occasionally disappear down a rabbit hole for no particularly grand reason.

The subjects vary. SEO, data, movies, web technologies, and whatever else happens to spark my curiosity. Some things start as practical problems looking for solutions. Others begin with a simple *"I wonder what happens if..."* and go wherever that takes them.

There's no grand plan behind it all. Just a place to explore, learn, make things, and occasionally share something useful along the way. Preferably on an open web that still has a little room for human curiosity.

Have a look around at [alexanderkyriakou.eu](https://alexanderkyriakou.eu).
